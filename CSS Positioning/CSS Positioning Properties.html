Understanding position: static

The default value — elements flow in document order. Offsets like top and left have no effect here.

Understanding position: relative

Elements keep their space but can be nudged visually. Great as an anchor for absolute children.

Understanding position: absolute

Removed from flow and anchored to the nearest positioned ancestor. Perfect for badges and overlays.

Understanding position: fixed

Anchored to the viewport. Stays put no matter how far the user scrolls — like the navbar and FAB on this page.

Understanding position: sticky

Behaves like relative until a scroll threshold, then pins like fixed within its parent. See the sidebar and sub-header.

When to use which?

Static for default flow, relative for anchoring, absolute for overlays, fixed for viewport-pinned UI, sticky for scroll-aware headers.
